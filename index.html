4.2 Application 构造函数与 run()

构造函数里 new 三个控制器；run() 里先做管理员守卫，再 switch。受保护动作以外的首页/login/logout 任何人可见。

URL 参数调用说明
无 / 默认homepage('')显示登录表单或已登录文字

实现 Student::validate() 的五条规则

方法签名是 validate(): Array，不能加参数，所以直接在方法内部用 filter_input(INPUT_POST,...) 读表单——新增和编辑共用同一批字段名。

$name = filter_input(INPUT_POST, 'name');
if (empty($name)) {
    $errors[] = 'Please enter your fullname';
}
$sid = filter_input(INPUT_POST, 'sid');
if (!filter_var($sid, FILTER_VALIDATE_REGEXP,
    ['options' => ['regexp' => '/^\d{10}$/']])) {
    $errors[] = 'ID should be ten digit number';
}
$email = filter_input(INPUT_POST, 'email');
if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    $errors[] = 'Please enter the correct email address';
}
$dept = filter_input(INPUT_POST, 'dept');
if (!filter_var($dept, FILTER_VALIDATE_REGEXP,
    ['options' => ['regexp' => '/^(CSIS|BUS|MAR)$/']])) {
    $errors[] = 'Please select one of the departments';
}
$status = filter_input(INPUT_POST, 'status');
if (!filter_var($status, FILTER_VALIDATE_REGEXP,
    ['options' => ['regexp' => '/^(domestic|international)$/']])) {
    $errors[] = 'Please select one of the status';
}
空表单提交时页面显示对应字段
Please enter your fullnamename
ID should be ten digit numbersid（正则 /^\d{10}$/，空值也不通过）
Please enter the correct email addressemail
Please select one of the departmentsdept（限定 CSIS / BUS / MAR）
Please select one of the statusstatus（限定 domestic / international）
这里刻意没用 FILTER_SANITIZE_NUMBER_INT 去“清洗” SID：清洗会把 abc0123456789 变成合法数字而误判通过。验证要读原始值。

实现仓储层与登录控制器

Repository 只负责 SQL；连接来自 Database::getConnection()。全部使用 PDO 预处理 + bindParam，避免 SQL 注入。取对象时用 FETCH_CLASS 直接映射成 Student/User。

6.1 StudentRepository 五个方法

// findAll
$stmt = $this->connection->prepare('SELECT * FROM student');
$stmt->execute();
$stmt->setFetchMode(\PDO::FETCH_CLASS, Student::class);
return $stmt->fetchAll();

// find
$stmt = $this->connection->prepare('SELECT * FROM student WHERE id = :id');
$stmt->bindParam(':id', $id, \PDO::PARAM_INT);
$stmt->execute();
$stmt->setFetchMode(\PDO::FETCH_CLASS, Student::class);
$student = $stmt->fetch();
return $student == false ? NULL : $student;

// insert 返回 lastInsertId()，失败返回 -1；update 返回 bool；delete 返回 bool
// 字段：name, sid, email, dept, status（id 由数据库自增）

6.2 UserRepository::find 与 UserController::processLogin

// UserRepository: SELECT * FROM user WHERE username = :user
// 同样用 FETCH_CLASS + User::class

$user = $this->userRepository->find($username);
if ($username === 'admin' && $user && $user->verifyPassword($password)) {
    $_SESSION['username'] = $username;       // index.php 已经 session_start()
    header('Location: /?action=students');
    exit;
}

User::verifyPassword() 内部是 password_verify($passwordToVerify, $this->password)，和建库脚本里写入的 bcrypt 哈希配套。

insert/update 我包了 try/catch (\PDOException)：如果 SID 或 email 与已有记录重复（表上有 UNIQUE 约束），返回 -1 / false，由控制器显示一条友好错误，而不是白屏。

实现 StudentController 的七个动作

控制器负责“校验 → 调用仓储 → 渲染模板或跳转”。新增/编辑成功后把新记录 id 放进 $_SESSION['id']，列表页读取它来高亮那一行，并且读完后立刻 unset，避免下次还高亮。

7.1 列表与详情

$students = $this->studentRepository->findAll();
$id = $this->getIdFromSession();          // 提供的私有方法，原样保留
print $this->twig->render('student/list.html.twig',
    ['students' => $students, 'id' => $id]);

// show：find($id) 为 NULL 时渲染 error.html.twig

7.2 新增与编辑的处理流程

$errors = Student::validate();
if (count($errors) === 0) {
    $newId = $this->studentRepository->insert($data);   // edit 用 update($data)
    if ($newId > 0) {                                  // update 返回 true
        $_SESSION['id'] = $newId;                        // edit: (int)$data['id']
        header('Location: /?action=students');
        exit;
    }
    $errors[] = 'Unable to add the student - SID or email may already exist';
}
// 有错：把 errors 和 data 一起传回模板，保留用户刚填的内容
print $this->twig->render('student/create.html.twig',
    ['errors' => $errors, 'data' => $data]);
